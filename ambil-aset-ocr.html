Siapkan OCR offline

Halaman ini mengunduh mesin dan model OCR, lalu mengemasnya jadi satu file vendor.zip. Tidak perlu memasang apa pun. Butuh internet dan browser di laptop, dan cukup dilakukan sekali.

Siap. Tekan "Mulai unduh".

Setelah vendor.zip terunduh

  1. Ekstrak vendor.zip sehingga muncul folder vendor.
  2. Buka repo GitHub-mu, pilih Add file → Upload files.
  3. Seret folder vendor ke halaman itu (taruh di tempat yang sama dengan index.html), lalu Commit changes.
  4. Tunggu GitHub Pages selesai membangun (sekitar 1 menit), lalu buka aplikasinya. OCR offline akan disiapkan sendiri di latar belakang.
